# X 界面精简

面向 X（Twitter）网页版的 Tampermonkey 用户脚本。隐藏多余侧栏与悬浮入口，适配宽屏阅读，并提供干净的分享链接、快捷关注和 Pixiv 资料链接补全。

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击[安装脚本](https://raw.githubusercontent.com/rbqgroup/tampermonkey-scripts/main/twitter-minimal/dist/twitter-minimal.user.js)，在 Tampermonkey 页面确认安装。
3. 确认脚本已启用，打开或刷新 [X 主页](https://x.com/home)。

也可将 [`dist/twitter-minimal.user.js`](./dist/twitter-minimal.user.js) 的完整内容粘贴到 Tampermonkey 新建脚本中并保存。不要将代码粘贴到 X 的发帖框。

建议使用最新版桌面 Chrome 或 Edge。脚本匹配 `https://x.com/*` 和 `https://twitter.com/*`，不在 iframe 中运行，不需要额外的运行时依赖。

## 功能

### 精简界面

- 隐藏整个右侧栏。
- 左侧只保留主页、探索、通知、聊天、历史、个人资料和更多。
- 隐藏左侧 X 标志、独立发帖按钮与底部账号菜单；不移除主页中的发帖框。
- 隐藏右下角的 Grok、聊天悬浮入口及其抽屉，不影响左侧聊天入口。

### 响应式布局

通过 CSS 媒体查询适配视口宽度，不使用 JavaScript 持续监听窗口尺寸。

| 视口宽度 | 布局 |
| --- | --- |
| ≥ 1440px | 导航宽 240px，时间线最大宽度 1000px |
| 768–1439px | 导航收为 72px 图标栏，时间线随可用空间伸缩 |
| < 768px | 不重写原生窄屏导航，主内容随可用空间收缩 |

桌面布局以**时间线自身**对齐屏幕中心，而非将导航与时间线整体居中。两侧为导航预留等宽空间，空间不足时内容会收缩。推文卡片和操作栏随正文展开，保留原生按钮的弹性分布。

### 干净的分享链接

保留原生分享入口，在网站写入剪贴板或调用系统分享时净化链接：

- 推文链接移除查询参数与片段，例如 `https://x.com/example/status/123?s=20&t=tracking` 变为 `https://x.com/example/status/123`。
- 其他 X/Twitter 链接仅移除已知追踪参数，保留功能参数。
- 不改写普通文本或其他网站的链接。

### 快捷关注

在能够确认作者尚未被关注时，在作者名称旁显示“关注”按钮。按钮位于姓名资料卡的 hover 容器之外，不应因悬停在按钮上而弹出作者资料卡。

点击后复用该作者的原生关注菜单，不额外实现独立的账号操作接口，也不会主动批量关注。

| 按钮状态 | 含义 |
| --- | --- |
| 关注 | 可以提交关注操作 |
| 关注中 | 正在等待结果，禁止重复提交 |
| 已关注 | 关注操作已成功 |
| 已请求 | 已发送需要对方批准的关注请求 |
| 重试关注 | 请求明确失败，可查看提示后重试 |
| 待确认 | 等待超过 15 秒，但尚未收到明确结果，继续等待并阻止重复提交 |

状态按作者缓存在当前页面，同一作者出现在多张卡片时同步更新。刷新后重新读取网站数据，不使用持久化关系缓存。作者状态无法识别时不显示按钮，不会为了补全状态逐个请求作者主页。

### Pixiv 资料链接

当作者资料中存在直接的 Pixiv 链接时，在原生悬浮资料卡中补充可点击链接：

- 读取页面已加载的资料，包括个人主页字段和简介中的展开链接。
- 使用 X 提供的展开地址解析 `t.co` 链接，不另行请求短链。
- 支持 `pixiv.net`、`www.pixiv.net`、语言前缀和旧式 `member.php?id=…` 主页地址。
- 同一链接去重，简介中已经显示的链接不重复添加。
- 点击后在新标签页打开 Pixiv，并设置 `noopener noreferrer`。

不会访问 Pixiv 获取作品，也不会进入 Linktree、`lit.link` 等聚合页面寻找间接链接。资料未加载或没有可用展开地址时，可能无法补全链接。

### 保守省流

- 在页面的 Fetch、XHR 和 Beacon 调用中拦截已知 Jot/Scribe 统计路径，匹配范围限定为 X/Twitter 及其 API 域名。
- 限制视频自动播放，将尚未允许播放的视频预加载策略设为 `none`；点击视频区域后允许播放。
- 在线注入预览时，不打断已经开始播放的视频。

统计路径参考 [EasyPrivacy](https://easylist.to/easylist/easyprivacy.txt)。用途未确认的 CES 请求、时间线、登录、关注、聊天和图片接口不在拦截范围内。

这不是完整的广告拦截器：页面可能自行预取媒体，Worker 或其他加载方式也可能绕过页面方法拦截，因此不能保证消除所有遥测或视频流量，也不承诺固定的加载速度收益。

## 权限与隐私

- 使用 `@grant none` 和 `@sandbox raw`，在页面上下文运行，以接入网站实际使用的剪贴板及网络方法。
- 不申请 `GM_*` 扩展权限或跨域请求权限，不加载外部脚本。
- 不主动读取系统剪贴板，链接净化发生在复制或分享过程中。
- 不额外请求作者主页，不向脚本自有服务器上报数据。
- 关注操作使用网站当前登录会话；页面上下文并非安全隔离沙盒，安装前可阅读源码。

## 开发

在仓库根目录执行：

```bash
npm install
npm run build -w twitter-minimal
```

或在本目录执行 `npm run build`。根目录的 `npm run build` 会构建全部 workspace。

| 文件 | 用途 |
| --- | --- |
| [`src/twitter-minimal.user.js`](./src/twitter-minimal.user.js) | 脚本源码与安装元数据 |
| [`build.mjs`](./build.mjs) | 检查 JavaScript 语法，再原样输出源码 |
| [`dist/twitter-minimal.user.js`](./dist/twitter-minimal.user.js) | 可直接安装的构建产物 |

构建不会执行用户脚本，也不进行打包转换。此 workspace 使用原生 JavaScript，没有 TypeScript 类型检查命令。修改源码后需重新构建；发布时保持源码元数据、运行时版本与 `package.json` 版本一致。

仓库 CI 会构建脚本并在产物变化时提交更新。已安装脚本通过元数据中的 `@updateURL` 和 `@downloadURL` 检查及下载更新，具体检查时机由 Tampermonkey 设置决定。

## 限制与排查

- 依赖 X 当前的页面结构、React 内部资料及原生菜单，网站改版后可能需要适配。
- 脚本在 `document-start` 接入网络方法；安装或更新后，请刷新已经打开的 X 页面。
- 如果只有控制台临时预览而没有安装脚本，刷新后样式和行为可能失效。
- 关注显示“待确认”时，请查看原生界面或刷新后确认关系，不要绕过等待状态重复提交。
- 视频仍有后台请求时，可能来自网站自行预取或其他加载路径，预加载策略并非浏览器级网络封锁。
- 当前没有设置面板。停用脚本并刷新页面即可恢复网站原生界面和行为；这不会撤销已经完成的关注操作。
